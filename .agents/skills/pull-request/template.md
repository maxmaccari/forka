# Pull Request Body

Used when the repo has no PR template. Fill it, drop any section or link whose value is unknown, and keep the whole body on one screen (SKILL.md, Step 4).

```markdown
## Summary

- [What changes for users or the business, and why]

## Changes

1. [Commit subject, in order; drop this section for a single commit]

## How to test

1. [A step a reviewer can run; or "Covered by tests"]

## Notes

- [A decision, risk, or follow-up the reviewer needs]

---

Spec `docs/specs/YYYY-MM-DD_<slug>_spec.md` (slice N of M) · Roadmap `R-XX` · Closes #NN

_Drafted by [Agent] ([Model])._
```
